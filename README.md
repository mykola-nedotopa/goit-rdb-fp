# Фінальний проєкт з реляційних баз даних

Фінальний проєкт до курсу **Relational Databases: Concepts and Techniques**.

Роботу виконано з використанням **MySQL** та **MySQL Workbench**.

## Виконані завдання

1. Створено схему бази даних `pandemic` та імпортовано набір даних `infectious_cases`.
2. Початкову таблицю нормалізовано до третьої нормальної форми (3NF).
3. Проведено аналіз атрибута `Number_rabies` із використанням агрегатних функцій.
4. Побудовано дату першого січня відповідного року, поточну дату та розраховано різницю між ними в роках за допомогою вбудованих функцій MySQL.
5. Створено та використано власну SQL-функцію для розрахунку різниці в роках.

## Файли проєкту

* `final_project.sql` — SQL-код для виконання всіх завдань фінального проєкту.
* `infectious_cases.csv` — початковий набір даних.
* `01_schema_tables.png` – `09_task5_function_1996.png` — скриншоти структури бази даних, SQL-запитів та результатів їх виконання.
